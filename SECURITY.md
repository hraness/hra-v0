# HRA v0 security policy

## Archive status

HRA v0 ended at v0.1.16 build 17. No HRA v0 release is maintained or
supported, and the hosted Vercel and Convex services were retired on August
27, 2026. This repository receives no security fixes.

## Supported versions

No HRA v0 version is supported. HRA and its successor Oompa are retired.
Reports that affect their successor, xcb, belong in its
[security policy](https://github.com/hraness/xcb/security/policy). Do not
assume a report against this archived desktop or web code applies to xcb.

## Disclosure

The retired product trust boundaries and known limits are documented in
[SECURITY_ARCHITECTURE.md](SECURITY_ARCHITECTURE.md).
